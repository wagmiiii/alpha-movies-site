# Reference site notes: directorengineer.framer.media

Status: notes from a text-only read of the page. I could not see colors, motion or typography. This is a freelance editor template, not a production house, so adapt mechanics, not positioning.

## Worth adapting

- Category-tagged project cards, each linking to its own project page.
- A vertical short-form showcase row.
- Numbered services with tag chips.
- A named process.
- A response-time promise next to the form.
- A public starting price with scope bullets.
- A scarcity badge, only if true.

## Avoid

- Template copy errors: a process step repeats another step's text, and the FAQ describes corporate videos and animation on a page priced as a freelance editor.
- Placeholder stats such as view counts and client counts.
- Several autoplaying muted YouTube embeds in the hero.
- Its budget dropdown (we decided against any budget field).
- A tel: link as the main contact. Use wa.me for Nigerian clients.

## Missing from the template, and our differentiators

No registration details, equipment list, press mentions or collaborations. No date or availability capture.
